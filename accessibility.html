Accessibility Statement

Making Melody usable for everyone

Melody aims to make this website accessible and usable for visitors with disabilities, including people using assistive technologies.

Last updated: June 3, 2026

Our target

The site is designed with WCAG 2.2 AA principles in mind, including readable structure, keyboard-accessible links and controls, semantic HTML, responsive layouts, and sufficient text contrast.

Current measures

  • Pages use semantic headings, labels, and landmark-style structure.
  • Forms include visible labels and clear error messages.
  • Navigation and app cards can be reached with a keyboard.
  • Text uses local system fonts and scalable layouts.
  • No autoplaying media, flashing content, or forced motion is used.

Known limitations

This is an early static site and has not yet been audited by an external accessibility specialist. As the employee apps and authentication experience become real products, those surfaces should be tested separately.

Feedback

If you find an accessibility issue, email privacy@melodyvc.com with the page URL, a description of the issue, and the assistive technology or browser you were using if relevant.
